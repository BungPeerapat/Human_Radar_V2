Human Radar V2 — Wiring Diagram

ESP32-WROOM32 ↔ HLK-LD2450 (24 GHz mmWave radar)

คำตอบเร็ว ๆ: GPIO26 ไม่ได้ถูกใช้ ในเฟิร์มแวร์เลย — ตรวจจาก Human_Radar_V2.ino และโมดูลทั้งหมด ไม่มี pinMode(26, …) หรือการอ้างอิง GPIO26 ใด ๆ จึงเป็นพินว่าง (free) ใช้ต่ออุปกรณ์เพิ่มเติมได้ เช่น LED, buzzer, ปุ่ม ฯลฯ

1) สรุปการต่อสาย LD2450 → ESP32 (4 เส้น)

LD2450ทิศทางESP32-WROOM32หมายเหตุ
VCC (5V)→ 5V / VIN LD2450 ใช้ 5V (กินกระแส ~80 mA peak)
GND↔ GNDต่อ GND ร่วมกัน
TX→ GPIO16 (RX2) ข้อมูล radar 256000 baud (UART2 RX)
RX← GPIO17 (TX2) ESP32 ส่งคำสั่ง (UART2 TX)

● Power 5V ● Ground ● UART2 ● Free

3) สถานะของแต่ละ GPIO บน ESP32 ที่ใช้/ไม่ใช้

GPIOสถานะหน้าที่ในโปรเจกต์
GPIO16 USED UART2 RX ← LD2450 TX (รับเฟรมเรดาร์ 30 ไบต์ที่ 10 Hz)
GPIO17 USED UART2 TX → LD2450 RX (ส่งคำสั่งคอนฟิก, ปัจจุบันยังไม่ใช้คำสั่ง)
GPIO26 FREE ไม่ได้ใช้งานในเฟิร์มแวร์ — ต่อเพิ่มได้ (DAC2, ADC2_CH9 ก็ได้)
GPIO25, 27, 32, 33 FREE พินว่างทั่วไป ใช้เป็น GPIO/PWM/ADC ได้
GPIO0, 2, 12, 15 STRAPPING เป็น strapping pin — ระวังตอน boot, ไม่ควรต่ออุปกรณ์ที่ดึงระดับขณะรีเซ็ต
GPIO6–11 FLASH ต่อกับ SPI flash ภายใน — ห้ามใช้
GPIO34–39 INPUT-ONLY อ่านค่าได้อย่างเดียว ไม่มี internal pull-up/down

4) ข้อแนะนำเรื่องไฟเลี้ยงและสัญญาณ

ไฟเลี้ยง
  • LD2450 ระบุ 5V; ESP32 ใช้ 3.3V ภายใน
  • ใช้ขา 5V/VIN ของบอร์ด ESP32 จ่ายตรงเข้า LD2450 ได้
  • ถ้าจ่ายจาก USB ของคอม กระแสเพียงพอ (~500 mA)
  • เพิ่ม cap 100 µF + 100 nF ใกล้ขั้ว LD2450 ถ้ามี noise
UART logic level
  • LD2450 TX เป็น 3.3V logic — ต่อตรงเข้า GPIO16 ได้เลย ไม่ต้อง level-shift
  • ESP32 TX (3.3V) → LD2450 RX อยู่ใน input range ปกติของบอร์ด
  • ความเร็วสูง 256000 baud — สายควรสั้น (< 30 cm) หรือใช้สายชีลด์

5) อ้างอิงในซอร์ส

  • Human_Radar_V2/Human_Radar_V2.ino:44-45 — RADAR_RX_PIN = 16, RADAR_TX_PIN = 17
  • Human_Radar_V2/radar_driver.h:16 — radar.begin(16, 17); // RX=GPIO16, TX=GPIO17
  • LD2450 settings: 256000 8N1, RX buffer 512B (ESP32-WROOM32 specific)

6) ถ้าจะใช้ GPIO26 ในอนาคต

GPIO26 ว่างและปลอดภัย ใช้กับ:
  • ไฟ LED แสดงสถานะตรวจจับ (active-high, ผ่าน R 220–470 Ω)
  • ขา trigger ของ buzzer / relay
  • DAC2 ออก analog 0–3.3V (เช่นเสียงเตือนจากชิป)
  • ADC2 (ใช้ได้เมื่อไม่เปิด WiFi อ่านพร้อมกัน — ESP32 ADC2 share กับ WiFi)
